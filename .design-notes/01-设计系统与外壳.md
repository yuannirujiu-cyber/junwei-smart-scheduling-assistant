- 三个 `*-root` 容器都在 `.app` 之外，因此不受 `overflow:hidden` 的骨架裁剪影响（`web/assets/app.css:52`）。

### 3.2 "不只依赖红绿"的实现手段（逐条可核）

1. **颜色 + 文字标签成对出现**：`.sev-pill` 输出的是汉字而非色块——`阻断 / 警告 / 提示`（`web/src/components/ui.js:273-277`）；`dueTag` 输出 `硬交期 / 软交期 / 交期政策待确认`（`web/src/components/ui.js:7-9,261-264`）；`versionTag` 输出 `基于旧数据 / 已确认 / 已替代 / 待重算 / 可确认 / 草稿（存在阻断）`（`web/src/components/ui.js:497-506`）。
2. **图标作为第二通道**：`tag()` 第 3 个参数是图标名并渲染 11px 图标（`web/src/components/ui.js:257-259`；尺寸见 `web/assets/app.css:164`）；风险项按等级映射图标 `block→alert, warn→info, info→dot`（`web/src/components/ui.js:313-316`）；Toast 映射 `ok→check, err→alert, warn→info, 默认→dot`（`web/src/components/ui.js:450`）；`.banner .ico` 16px（`web/assets/app.css:205`）；`lockTag` 用 `pause`/`lock` 图标区分"执行冻结"与"已锁定"（`web/src/components/ui.js:269-270`）。
3. **边框 + 斜纹图案作为第三通道**：
   - 阻断风险 `.g-task.risk-block`：`border:2px solid var(--block)` + `repeating-linear-gradient(45deg, rgba(255,255,255,.24) …, transparent …)`（`web/assets/app.css:337`）
   - 警告风险 `.g-task.risk-warn`：`border:2px solid var(--warn)` + `-45deg` 同款斜纹（`web/assets/app.css:338`）
   - 换型条：紫色 45° 斜纹 + `#c4b5fd` 边框（`web/assets/app.css:343-345`）
   - 停机条：灰 `#cbd5e1/#94a3b8` 45° 斜纹（`web/assets/app.css:346`）

   - 等待条：横向虚线（`90deg`）5px 高，超额时换 `--block` 色（`web/assets/app.css:348-349`）
   - 夜间时段：`135deg` 斜纹底（`web/assets/app.css:306`）
4. **形状/尺寸差异**：任务条 19px 高（`app.css:329`）＞ 停机条 15px（`346`）＞ 换型条 13px（`343`）＞ 等待条 5px（`348`）；交期线是 1px 竖线（`314`）、"现在"线是 2px 竖线（`313`）、宽限期是渐变色带（`gantt.js:406`）。

7. **CSS 注释层面对该约束的显式声明**：「工序语义色（图形与文字同时使用，不单独依赖颜色）」（`web/assets/app.css:20`）。

### 6.2 双视角行结构（`buildRows`，`gantt.js:100-159`）

**设备视角（`ui.gantt.view === 'machine'`，`gantt.js:115-137`）**，按 `PROCESSES` 顺序（拉丝 → 捻股 → 合绳）逐工序生成：
1. `kind:'group'` 工序分组行：`label=工序名`、`count=该工序设备总数`、`active=其中有任务的台数`、`collapsed` 取自 `ui.gantt.collapsed['grp:'+key]`（`gantt.js:122`）
2. `kind:'machine'` 设备行（仅含有匹配任务的设备）：`label=机台号`、`sub=设备名`、`occ = Σ(任务时长 + setupHours)` 小时（`gantt.js:126-128`）
3. `kind:'idle'` 空闲设备聚合行：`count=空闲台数`，折叠状态取 `ui.gantt.expanded['idle:'+key]`（注意：**空闲组默认折叠**，`collapsed: !idleOpen`，`gantt.js:133`）；展开后追加设备行但任务数组为空（`gantt.js:134`）

**订单视角（`gantt.js:141-158`）**：
1. `kind:'order'` 订单父行：候选来自 `version.model.active` 且必须已有排产任务（`gantt.js:141-144`）；分页 `limit = ui.gantt.orderLimit || 40`（`gantt.js:145-146`）；`start/end` 取该订单所有任务的 min/max（`gantt.js:152`）
2. `kind:'op'` 工序子行（仅 `expanded` 时）：按 `['drawing','stranding','closing']` 固定顺序生成，`parentKey = 'o:'+orderId`（`gantt.js:153-156`）

**行模型 → DOM**（`row()`，`gantt.js:366-378`）：
`div.g-row[.grp][.sub][.sel][style height][data-row=key][role="row"][aria-level=1|2][aria-rowindex=N][aria-expanded?]` › `div.g-label[role="rowheader"][style width:300px]` + `div.g-track[style width]`。

## 7. `web/src/core/dom.js`：极简视图层

### 7.1 模板与转义规则

- `const RAW = Symbol('raw')`（`dom.js:3`）；`raw(s)` 返回带 `RAW` 标记且实现 `toString/valueOf` 的对象，字符串拼接时至少得到原文（`dom.js:4-13`）；`isRaw`（`dom.js:14`）
- `str(v)` 转义规则（`dom.js:16-21`）：
  - `null` / `undefined` / `false` / `true` → 空串
  - `isRaw` → 原样输出（**唯一的信任通道**）
  - 数组 → 递归 `map(str).join('')`
  - 其它 → `String(v).replace(/[&<>"']/g, …)`，映射为 `&amp; &lt; &gt; &quot; &#39;`（**注意：不转义反引号与等号，属性值必须自带引号**）
- `html\`…\``（`dom.js:23-30`）：顺序拼接 `strings[0] + str(vals[i]) + strings[i+1]`，返回 `markRaw(String 包装对象)`（`dom.js:31-37`），使内层模板插入外层时不被二次转义
- `esc = str`（`dom.js:38`）
- 使用约定：组件里凡是拼 HTML 片段进模板的，都要 `raw(...)`（例：`ui.js:226,252-253,300,314,472,489`），文本则直接插值走转义

### 7.2 元素与查询工具

- `el(tag, attrs={}, ...kids)`（`dom.js:41-60`）：`tag` 支持 `div.cls#id` 形式；`attrs` 特殊键：`class`（追加）、`style`（对象 → `Object.assign(node.style, v)`）、`html`、`text`、`on*`（函数 → `addEventListener`）、`dataset`，其余 `setAttribute`（值为 `true` 时写空串；`null`/`false` 跳过）
- `add(node, kids)`（`dom.js:61-67`）：`kids.flat(9)`，跳过 `null/false/true/''`，Node 直接 append，其余转文本节点
- `frag`（`68`）、`qs(sel, root=document)`（`69`）、`qsa(sel, root=document)` → Array（`70`）、`clear`（`71`）、`setHTML`（`72`）

### 7.3 事件委托机制

- `NATIVE_INTERACTIVE = ['BUTTON','A','INPUT','SELECT','TEXTAREA','SUMMARY']`（`dom.js:75`）
- `delegate(root, map, type = 'click')`（`dom.js:98-129`）：
  - 处理器匹配 `e.target.closest('[data-act]')` 且必须在 `root` 内（`dom.js:100-101`）
  - **`INPUT/SELECT/TEXTAREA` 上的 click 直接跳过**——表单控件交给 `input/change` 通道，避免读到变更前的值（`dom.js:102-104`）
  - 命中后 `e.preventDefault()` 再调用 `map[act](event, element, dataset)`（`dom.js:105-106`）
  - `type==='click'` 时**额外注册 keydown**（`dom.js:110-124`）：`Enter` / `' '` / `Spacebar` 在非原生控件上合成一次点击；若 `e.defaultPrevented` 为真则跳过（注释说明否则同一次 Enter 会开两次抽屉、焦点回不到原处，`dom.js:113-116`）

## 8. 与设计相关的硬约束（可从源码直接验证）

1. **颜色不得作为唯一信息通道**（三通道冗余：颜色 + 图标 + 文字/图案）
   - 显式设计声明：`web/assets/app.css:20`「工序语义色（图形与文字同时使用，不单独依赖颜色）」
   - 状态一律配文字：`阻断/警告/提示`（`ui.js:273-277`）、`硬交期/软交期/交期政策待确认`（`ui.js:7-9`）、`执行冻结/已锁定`（`ui.js:269-270`）、`基于旧数据/待重算/草稿（存在阻断）`（`ui.js:497-506`）
   - 状态一律配图标：`tag` 的 `ico` 参数（`ui.js:257-259`）、风险等级图标映射（`ui.js:313`）、Toast 图标映射（`ui.js:450`）
   - 状态一律配图案/边框：风险斜纹 + 2px 彩色框（`app.css:337-338`）、换型/停机/未排斜纹（`app.css:341-346`）、等待条虚线（`app.css:348-349`）
   - 图形状态写入可访问文本：`gantt.js:390-395`（aria-label 含风险与锁定文字）、`gantt.js:384-389`（title 同）
2. **焦点必须可见**
   - 统一规则：`:where(button,a[href],input,select,textarea,summary,[tabindex]):focus-visible{outline:3px solid var(--brand);outline-offset:2px}`（`app.css:469-470`），注释说明「用 `:focus-visible` 而不是 `:focus`，鼠标点击不会出现轮廓（任务条例外，见下）」（`app.css:467-468`）
   - 例外与补偿：页签/分段控件 `outline-offset:-3px`（`471`）；侧栏 `.nav-item` 用 `#93c5fd` + 负偏移（`472`）；甘特任务条 `:focus` **与** `:focus-visible` 都画轮廓（程序化聚焦也要可见）（`473-474`）；折叠控件 2px brand（`475`）；菜单项 `outline-offset:-2px`（`509`）
   - skip-link 聚焦时 `outline:3px solid var(--brand)`（`465`）；主区域被聚焦时不画轮廓（`512`）
   - `prefers-contrast: more` 下焦点轮廓改 `#000` + 4px（`532`）
3. **焦点管理是硬性要求（弹层）**：打开即把焦点移入（`ui.js:36-45`）；关闭归还 opener，元素已被移除则退回 `body`（`ui.js:47-57`）；只有栈顶层参与 Tab 陷阱与 Escape（`ui.js:12-15,66-84`）；关闭幂等（`ui.js:370-376,411-417`）。代码注释把这些列为「审查项」结果（`ui.js:15,388-390,437-439`）。
4. **动效必须可被系统偏好关闭**：`prefers-reduced-motion: reduce` 把 animation/transition 压到 `.001ms !important` 且 `scroll-behavior:auto`（`app.css:515-522`）；全局动效时长均在 `.1s–.22s` 区间（`93,119,150,231,235,252,255,269,486`），唯一的循环动画是 0.8s 的计算旋转指示（`436-437`）。
5. **对比度可被系统偏好加强**：`prefers-contrast: more` 覆盖 8 个令牌 + 加粗边框 + `.g-task` 边框 2px + 焦点 4px 黑（`app.css:525-535`）。
6. **数值必须等宽对齐**：`font-variant-numeric:tabular-nums` 用于 `.metric .v`（`app.css:154`）、`.nav-item .badge`（`app.css:76`）、`table.tbl td.num / th.num`（`app.css:191`）、`.hbar .vl`（`app.css:422`）、`.delta`（`app.css:411`）、`.chain .node .t`（`app.css:393`）。
7. **文本溢出必须显式声明**：`.ellip`（单行省略号）与 `.nowrap`（`app.css:193-194`）；甘特标签多处显式使用（`gantt.js:244,257-258`）。
8. **不出现整页滚动**：`.app{height:100vh;overflow:hidden}`（`app.css:52`）；滚动被限制在 `.view`/`.nav`/`.drawer-b`/`.modal-b`/`.tbl-wrap`/`.gantt-scroll`（`54,66,247,262,180,295`）。
9. **弹层滚动区底部留白**：`.drawer-b{padding:14px 16px 80px}`（`app.css:247`）。
10. **图标一律装饰性**：所有 `icon()` 输出 `aria-hidden="true"`（`dom.js:192`），语义必须由文字或 `aria-label` 承担。
11. **仅视觉隐藏的文本用于播报**：`.sr-only`（1px + `clip-path:inset(50%)` + `white-space:nowrap`，`app.css:458-459`），用于 `#live-root`（`index.html:26`）。
12. **触控尺寸**：源码中**没有**最小点击区（如 44×44）约束或 `min-height` 规则；由内边距推算的近似高度为：`.btn`≈32px、`.btn.sm`≈27px（`padding:4px 9px` + 11.5px 行高，`app.css:91,105`）、`.nav-item`≈34px（`padding:8px 10px` + 12.5px 行高，`app.css:70`）、`.menu-item`≈31px（`padding:7px 9px`，`app.css:499-500`）；甘特任务条固定 19px 高（`app.css:329`）——**明显小于常见触控基准，交互冗余依赖键盘可达性而非触控尺寸**（此为按声明值推算，非源码明示规则）。
